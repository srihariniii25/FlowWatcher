# Contributing to FlowWatcher

First off, thank you for taking the time to contribute!

Here are some important resources:
 
  * [Security Policy](SECURITY.md): If you need to share a security vulnerability, please refer to our Security Policy.
  * [License](LICENSE): FlowWatcher is open source under the Apache 2.0 license.
  * [Contributor License](https://docs.github.com/en/github/site-policy/github-terms-of-service#6-contributions-under-repository-license): The Apache 2.0 license applies to all contributions offered to the FlowWatcher project.
  * [Code of Conduct](CODE_OF_CONDUCT.md): The FlowWatcher community strives to be open and welcoming to all.

## How can I contribute?

### I'm having difficulty installing, operating or building FlowWatcher

Open a GitHub issue with the command you ran, the output, and your environment details.

### I think I have found a bug in FlowWatcher

If you believe you've found a security vulnerability, please refer to our [Security Policy](SECURITY.md).

For all other bugs, please first check if the issue has already been opened in this repository. If so, add details to the existing issue.

If the bug appears to be new, open a GitHub issue with enough information to reproduce it.

### I'd like to share a change to FlowWatcher

Please send a GitHub pull request with a clear explanation of what you are changing and why.

Code Style: we're flexible and accomodating. Copy the style of the code adjacent to your contributions, keep it clear and easy to understand for other developers and we're all good.

### I have an idea for an enhancement to FlowWatcher

If it is a well-formed enhancement, open a GitHub issue explaining who it benefits and why it is important.

Please include relevant examples or implementation details in the issue.

## I'd like to talk to someone directly

Please use the repository issue tracker for project questions.
